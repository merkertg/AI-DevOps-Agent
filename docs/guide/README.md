# Учебные материалы AI DevOps Agent

[README](../../README.md) · [Дорожная карта](../ROADMAP.md)

Подробное руководство первого этапа находится в [STAGE_01.md](../STAGE_01.md).
В нём объяснены текущие файлы, запуск, путь запроса, настройки, тесты и типичные
ошибки. Краткие английские инструкции:
[запуск](../instructions/quickstart.md), [использование](../instructions/usage.md),
[проверки](../instructions/testing.md), [структура](../instructions/project-structure.md).

Фактические результаты хранятся в [VERIFICATION.md](../VERIFICATION.md),
машинная сводка — в [verification.json](verification.json), выполненные шаги —
в [журнале разработки](../DEVELOPMENT_LOG.md).

На этапе 01 руководство распространяется в Markdown. PDF-генератор и PDF-файлы
не создаются. При добавлении такого формата потребуется отдельная проверка
содержания и визуального результата; наличие Markdown не означает наличие PDF.

Материалы следующих этапов добавляются вместе с их реализацией. После изменения
поведения нужно обновить затронутые инструкции и результаты проверок, а затем
закоммитить и отправить завершённый этап по [правилам публикации](../CI_CD.md).
