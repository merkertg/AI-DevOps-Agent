# Проверка проекта

Дата: 2026-10-23. Этап: 01. Среда: macOS arm64, Python 3.12.15,
uv 0.12.23. Проверки выполнены локально на исходниках этого этапа.

## Реализовано

- FastAPI, фабрика приложения и `GET /health`.
- Валидация настроек `APP_NAME`, `APP_ENV`, `APP_DEBUG`.
- Тесты, Ruff, строгий mypy, проверка локальных Markdown-ссылок.
- Конфигурация GitHub Actions и документация по этапам.

## Локальные проверки

| Проверка | Результат |
| --- | --- |
| `uv sync --locked` | успешно; 33 пакета в разрешённом графе, 30 установлено в текущей среде |
| `uv lock --check --offline` | успешно; lock-файл соответствует проекту |
| `uv run --locked ruff check .` | успешно |
| `uv run --locked ruff format --check .` | успешно |
| `uv run --locked mypy app tests scripts` | успешно; 7 файлов |
| `uv run --locked pytest` | 32 passed, без пропусков |
| `uv run --locked python scripts/check_docs.py` | успешно; 70 локальных ссылок в 14 Markdown-файлах |
| `git diff --check` | успешно |

Отдельно проверен реальный Uvicorn через HTTP на `127.0.0.1`
с временным свободным портом. `/health`, `/docs`, `/redoc` и
`/openapi.json` ответили `200`. `/` и `/incidents` ответили `404`.
Тело `/health` совпало с `{"status":"ok","service":"ai-devops-agent"}`.
После проверки временный сервер остановлен.

Тесты проверяют настройки, порядок источников, ошибки валидации,
кеш настроек, независимость экземпляров приложения, HTTP-контракт и
OpenAPI. Они используют временную рабочую папку и очищенное окружение
`APP_*`; реальные сервисы и локальный `.env` разработчика не требуются.

Использованы FastAPI 0.143.0, Starlette 1.7.0, Pydantic 2.14.0,
pydantic-settings 2.15.0, Uvicorn 0.54.0, HTTPX2 2.13.1,
pytest 9.1.1, mypy 2.4.0 и Ruff 0.16.10. Точные зависимости и хеши
сохранены в `uv.lock`; дата отсечения новых релизов — 2026-10-09.

Удалённый CI: `not_verified`. Workflow подготовлен для push и pull request

`633365b6b33059422fc69f37a08c85f35cd800ca`.
Коммит и push выполняются после финальных проверок; их фактический
результат сообщается пользователю отдельно после публикации.

## Особенности среды проверки

Стандартный кеш uv недоступен в песочнице, поэтому для запуска проверок
использован `UV_CACHE_DIR=/private/tmp/ai-devops-agent-uv-cache`.
Установка зависимостей и реальный HTTP smoke test потребовали разрешённого
выхода из ограниченной песочницы: DNS и локальный bind внутри неё запрещены.
После разрешения обе проверки прошли. Это ограничения среды выполнения,
а не ошибки приложения.

## Ограничения

`/health` — liveness: ответ приложения, а не проверка внешних систем.
Логи, Docker, история деплоев, хранение расследований, AI, метрики и трассы
пока только запланированы. Тесты не подтверждают работу этих интеграций.
